# Application icon

`icon.png` is the source artwork generated with the built-in imagegen tool on
2026-09-29. `icon.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel Windows
representations of the same artwork. The application and Nuitka build both use
`icon.ico`.

Friendly composed expression, clean strong silhouette, restrained teal/indigo/light cream colors, bold shapes legible at 32 and 48 pixels, professional illustrated app icon, simple softly rounded square dark indigo tile behind the head, generous safe margins, subtle dimensional shading, front view. No words, no letters, no branding, no official Live2D logo, no detailed background, no extra tiny objects. Final production icon artwork, not a mockup or grid of options.
