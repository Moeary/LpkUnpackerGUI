# Live2D PSD 改图指南

## 先选编辑坐标

PSD 是绘图界面，`.lpkpsd.json` 记录回写映射，`.baseline/` 保存导出时的图层基准。最终供模型使用的仍然是图集 PNG。

| 模式 | 图层排列 | 导出范围 | 回写方式 |
| --- | --- | --- | --- |
| 人物姿态 `mesh` | 当前姿态，类似模型渲染画面 | 完整人物 / 场景，或所选 ArtMesh | 按导出姿态的三角形逆映射到原图集 |
| 图集拆层 `atlas-components` | 原贴图像素，类似分层 UV 图 | 全图集透明连通区域，或所选 ArtMesh 的 UV 区域 | 直接映射到原图集像素坐标 |

**人物姿态更直观**：部件保持人物上的相对位置，适合改眼睛、袖口或局部图案。导出的是当时姿态的近似分层渲染，遮挡、透明、裁剪与缩放会影响可编辑内容；不是原作者 PSD。需要尽量保留细节时可使用原尺寸（最大边长设为 0）。

**图集拆层更精确**：完整导出按 alpha 连通区域分层，不保证一个区域等于一个 ArtMesh。若要准确选几个部件，应从“部件与选区”多选 ArtMesh 后导出图集模式；它按 UV 提取原始贴图像素，不受当前姿态是否可见影响。

新界面只提供这两种模式。旧 `atlas-artmesh` 的 PSD 与元数据继续支持读取和回写；底层兼容接口与验收夹具保留，不再作为独立用户入口。

## 完整人物或图集改图

1. 打开 Live2D 编辑器，在“外观”选择要编辑的皮肤。
2. 在 PSD“生成”页选参数预设、名称和模式。人物模式还可设置画布最大边长。
3. 点击“导出 PSD”，完成后直接点“编辑 PSD”。配置了 Photoshop 时使用它；否则交给系统默认 PSD 应用。
4. 外部保存后切到“回写”，选择刚导出的 PSD，生成贴图版本。
5. 在编辑器内，回写结果保存为新皮肤并应用，可撤销；动作保持不变。历史版本仍可另存为皮肤。
6. 点“改前 / 改后对比”检查结果。顶部“保存工程”把皮肤库、PSD 基准及历史另存到完整工程副本。

若系统无法打开 PSD，请在设置中指定 Photoshop，或在 Windows 配置 PSD 文件的默认应用。PSD 的生成和回写本身不依赖 Photoshop。

## 只改几个部件

1. 进入“部件与选区”，在模型或 ArtMesh 列表中多选；支持 Ctrl / Shift 和框选。
2. 点“选区 PSD”，在同一个对话框中填写名称，选择人物姿态或图集拆层。
3. 人物模式保持部件之间的相对位置，只收小画布；隐藏部件需要在导出副本中恢复可见。
4. 图集模式可勾选“紧凑重排所选部件”。程序以原分辨率排列各部件，避免重叠，不旋转或缩放图块；取消勾选则保留原图集位置。
5. 编辑并回写。元数据同时保存 PSD 位置与原图集位置，因此紧凑重排不会更改 MOC 或模型 UV。

选区导出应保持画布、单元位置与尺寸。修改单元里的原始像素，或在 `Paint` / `AI_Edit` 组内加修改层；可重命名带持久 ID 的层。完全擦除原像素时要实际擦除原始层，叠一张透明图层不会擦掉其下方内容。

同一批所选 ArtMesh 若共享 UV，给同一像素写入不同颜色会报冲突。所选部件与未选部件共用像素时，默认拒绝连带修改；确认需要一起改动后，在单个 PSD 的回写页勾选“同步修改共享部件”。界面和报告列出相关部件。UV 范围外的绘制不会扩张模型网格。

## 改前 / 改后对比

回写后在“回写”页点击对比；历史中的单个回写版本也可重新对比。左侧基准是该 PSD **导出时**的固定贴图，而不是此刻选中的皮肤。右侧是对应版本的回写 PNG。

- **左右对比**：同步构图并排查看。
- **滑动对比**：移动分界滑块查看相同位置。
- **差异高亮**：标出 RGBA 任一通道改变的像素，包含擦除与透明度修改。
- **图集选择**：分别检查每张贴图，显示原分辨率下的变化像素数量与涉及 ArtMesh。
- **人物姿态**：嵌入 Live2D 编辑器时，以当前冻结姿态分别合成改前、改后贴图；这是 PSD 合成参考，可能与原生运行时渲染不同。

滚轮缩放，拖动平移，“适配”恢复全图。ArtMesh 影响列表根据变化像素与 UV 的相交关系计算，包含共享贴图部件，不表示它们在当前姿态一定可见。独立 PSD 页面缺少完整模型几何时，只能列出元数据中已有的部件。

对比为只读任务，在独立子进程计算。生成失败时展示错误；人物合成失败时仍可查看图集对比。

## 直接编辑 PNG

“外观”的图集区域选择一张工作贴图，点击编辑按钮；也可在嵌入的“回写”页点击“编辑当前图集 PNG”。外部编辑器保存后自动重载。编辑的是当前工作副本，不是历史版本或 PSD 不可变基准；要保留为独立外观，保存为新皮肤。

## 文件与兼容性

必须一起保留：

```text
example.psd
example.lpkpsd.json
example.baseline/
```

完整工程还保存原模型贴图快照。回写按图层基准比较 RGBA，未改的像素保留；选区 PSD 无修改往返保持 PNG 文件字节不变。缺少基准、贴图尺寸改变、元数据不匹配或输出覆盖源贴图时会报错。

完整人物 PSD 按渲染顺序生成普通像素层；选区和图集编辑单元带 `Original`、`Paint`、`AI_Edit` 子组。层绑定优先使用持久 ID，旧无 ID 文件仅接受严格的原名或 `原名_数字` 匹配。

多个 PSD 可按优先级合成回写，列表靠前者优先，模型和贴图身份必须匹配。共享 UV 的显式同步选项仅用于单个选区 PSD。`repack_report.json` 记录实际变化区域、冲突及共享部件影响。
