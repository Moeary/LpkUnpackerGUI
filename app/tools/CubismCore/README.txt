Place Live2DCubismCore.dll here to enable optional Cubism Core drawable export.

Expected development path:
  app/tools/CubismCore/Live2DCubismCore.dll

Expected packaged path:
  tools/CubismCore/Live2DCubismCore.dll

The DLL is not bundled by this project. Download Cubism SDK for Native from the
official Live2D website and copy the Windows x86_64 Core DLL here, or set one
of these environment variables:

  LPK_CUBISM_CORE_DLL=C:\path\to\Live2DCubismCore.dll
  LPK_CUBISM_CORE_DIR=C:\path\to\directory-containing-the-dll

package that includes the DLL.
