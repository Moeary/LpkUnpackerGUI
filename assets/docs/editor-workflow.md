# Live2D / Spine 编辑器工作流

## 打开与另存

1. 将模型、已解包目录或资源包拖入“资源预览”。预览保留播放、图片浏览和资源导出。
2. 有效模型载入后，点击“打开 Live2D 编辑器”或“打开 Spine 编辑器”。图片预览没有此按钮。也可从主侧栏进入编辑器直接打开模型。
3. 编辑器复制当前模型及依赖到独立工作会话。即使来源来自临时解包目录，后续切换预览也不会破坏编辑器资源。
4. 完成后另存到新的模型文件夹；再次打开副本即可继续编辑。打开另一模型或关闭程序时，有未保存修改会提示保存、放弃或取消。

Spine 若在预览中经过兼容转换，编辑器使用当前预览的版本；界面保留版本提示。源文件不会被转换缓存或另存操作覆盖。

## Live2D

- 在“参数”标签搜索参数名或 ID，调整已有参数并查看模型变化。
- 新建或复制动作，在时间线上选择参数轨道，添加关键帧；也可将当前选中参数值写入当前时间。
- 在“ArtMesh”标签查看部件与贴图位置。有父级 Part 的部件可调整预览透明度；此状态保存在副本编辑记录中，不重新编译 MOC。
- 在“贴图”标签编辑工作贴图或替换同尺寸图片。选择外部编辑器并保存后，文件监视器自动重载模型贴图；修改作用于工作副本。
- “MOD 管理”保留原有工程、皮肤与换装导出。“将当前编辑用于 MOD”先另存完整副本，再导入该工程。

## Spine

- 骨骼树、图层顺序和图集部件与原生模型预览联动。
- 选择骨骼可修改设置姿态；动画平移与旋转是相对设置姿态的偏移，缩放是倍率。
- 新建或复制动作，选择骨骼及通道编辑数值关键帧；slot 的 attachment 与显示状态可写入当前时间。
- 图集部件可导出 PNG 或用同尺寸 PNG 替换，保持原裁切范围。旋转及预乘 Alpha 自动处理。
- 输出为骨骼 JSON、atlas、贴图和编辑记录的独立目录。此页不会直接生成官方 `.spine` 工程；需要官方工程时，另用版本转换页与已安装的官方编辑器。

## 时间线与曲线

拖动菱形修改关键帧时间，拖动曲线节点修改时间和数值。Live2D 支持线性、阶梯、反向阶梯和贝塞尔插值；Spine 支持线性、阶梯和贝塞尔。可拖动贝塞尔控制点或输入控制点数值，数值表可展开精确编辑。页面提供撤销、重做、播放、暂停与循环，隐藏页会暂停播放。

运行时数据不能完整还原作者的 `.cmo3` / `.spine` 创作工程。本程序编辑已有参数、骨骼与动画结构；缺失的绑定、原始网格创作信息及 Live2D 形变参数不会自动生成。未支持的动画轨道保留原数据；跨版本转换的动画效果需另行检查。
