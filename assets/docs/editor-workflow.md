# Live2D / Spine 编辑器工作流

## 打开与另存

1. 将模型、已解包目录或资源包拖入“资源预览”。右侧工具随资源格式变化：Live2D 常显当前 / 总时长，可冻结当前姿态并调整参数与所属 Part 的预览状态；冻结后拖动时间修改姿态，再解除冻结时会从头重新播放该动作。ArtMesh 页默认展示当前动作的 Parameter 曲线参数，搜索可查看全部参数，这并非 ArtMesh 绑定关系表。图片使用中央大图和右侧竖向列表。预览调整用于查看模型，可保存的动作关键帧与工程编辑在编辑器中完成。
2. 有效模型载入后，点击“打开 Live2D 编辑器”或“打开 Spine 编辑器”。图片预览没有此按钮。也可从主侧栏进入编辑器直接打开模型。
3. 编辑器复制当前模型及依赖到独立工作会话。即使来源来自临时解包目录，后续切换预览也不会破坏编辑器资源。
4. 完成后另存到新的模型文件夹。Live2D 工程以根 `model.json` 为入口，配套 `lpk_live2d_editor.json` 记录编辑状态与相对子工程路径；再次打开此文件即可继续编辑。打开另一模型或关闭程序时，会统一检查模型、PSD 与 MOD 的未保存修改；后台任务结束前不能切换或关闭。

Spine 若在预览中经过兼容转换，编辑器使用当前预览的版本；界面保留版本提示。源文件不会被转换缓存或另存操作覆盖。

## Live2D

- 在“参数”标签搜索参数名或 ID，调整已有参数并查看模型变化。
- 时间轴上方的动作下拉框支持搜索；输入文字只筛选现有动作，按 Enter 选择唯一或完全匹配的结果。旁边的“＋ / − / 复制”分别新建、删除和复制动作。新建与复制先命名，删除需确认且可撤销；新建不是添加关键帧。
- 选择动作与参数轨道后添加关键帧，也可将当前选中参数值写入当前时间。另存保留原有 Live2DViewerEX 命令；仅提供运行时命令、没有动画文件的条目不作为可编辑动作。
- 在“ArtMesh”标签查看部件与贴图位置。有父级 Part 的部件可调整预览透明度；此状态保存在副本编辑记录中，不重新编译 MOC。
- 在“贴图”标签编辑工作贴图或替换同尺寸图片。选择外部编辑器并保存后，文件监视器自动重载模型贴图；修改作用于工作副本。
- “PSD 工作台”保留完整导出、图层回写、版本管理和外部编辑器工作流，以下入口均位于编辑器右侧，无重复模型预览区。
- “MOD 管理”保留工程创建、搜索切换、导入、重命名、删除、模型卡片与排序、主模型、皮肤名称、贴图图库及映射、ArtMesh/HitArea 换装配置和独立导出。工程搜索列出当前 `mods/` 中的工程及旧版工程记录；选中外部工程会导入副本，已导入工程可来回切换。“将当前编辑用于 MOD”把当前动作与贴图的独立快照导入工程内的 MOD。

### PSD 工作台入口

| 工作页 | 操作 |
| --- | --- |
| 导出与姿态 | 默认初始姿态、保存当前预览参数为命名预设、按预设导出 mesh / atlas-components / atlas-artmesh、画布尺寸限制 |
| PSD 回写 | 选择工程内或外部 PSD、指定或自动匹配元数据、外部编辑器、单 PSD 回写、多 PSD 排序优先级回写 |
| 版本与预览 | 原始 PSD 源快照、回写历史与复合版本、选择单张或全部贴图、图集查看、左侧模型预览、版本贴图应用和送 MOD |
| 工程与工具 | 新建或导入 PSD 子工程副本、搜索并切换 `psd/` 内或旧版记录中的工程、保存子工程设置、打开目录、静态 ArtMesh 检查器、输出目录与日志 |

导出时会从当前编辑模型生成独立快照，每次导出保留自己的 PSD、`.lpkpsd.json` 和 `.baseline/`。后续更改模型贴图或动作不会悄悄覆盖既有 PSD 的基准。`psd/` 包含源快照、姿态 PSD、回写历史、复合版本和预览资源；`mods/` 包含模型、贴图映射、皮肤副本与导出配置。导入旧子工程会复制依赖，原工程保持不变。

查看 PSD 或 MOD 版本只切换左侧预览。“返回当前模型”会恢复参数、所属部件状态和时间线，不丢弃未保存动作。应用 PSD 回写版本前会核对 MOC、贴图数量、顺序与尺寸；成功后只修改当前工作贴图，批量应用是一次可撤销操作。“送入 MOD”也使用当前动作，不以旧 PSD 快照覆盖它们。保存根工程时一并保存两个子工程，目录搬移后可重新打开。

## Spine

- 骨骼树、图层顺序和图集部件与原生模型预览联动。
- 选择骨骼可修改设置姿态；动画平移与旋转是相对设置姿态的偏移，缩放是倍率。
- 在可搜索的动作下拉框中选择现有动作；旁边“＋ / − / 复制”用于新建、确认删除和命名复制，均可撤销。选择骨骼及通道编辑数值关键帧；slot 的 attachment 与显示状态可写入当前时间。
- 图集部件可导出 PNG 或用同尺寸 PNG 替换，保持原裁切范围。旋转及预乘 Alpha 自动处理。
- 输出为骨骼 JSON、atlas、贴图和编辑记录的独立目录。此页不会直接生成官方 `.spine` 工程；需要官方工程时，另用版本转换页与已安装的官方编辑器。

## 时间线与曲线

关键帧工具的“＋”在当前时间给当前轨道添加关键帧，与动作下拉框旁的“新建动作”按钮分开，悬停提示会说明作用。拖动菱形修改关键帧时间，拖动曲线节点修改时间和数值。Live2D 支持线性、阶梯、反向阶梯和贝塞尔插值；Spine 支持线性、阶梯和贝塞尔。可拖动贝塞尔控制点或输入控制点数值，数值表可展开精确编辑。页面提供撤销、重做、播放、暂停与循环，隐藏页会暂停播放。

运行时数据不能完整还原作者的 `.cmo3` / `.spine` 创作工程。本程序编辑已有参数、骨骼与动画结构；缺失的绑定、原始网格创作信息及 Live2D 形变参数不会自动生成。未支持的动画轨道保留原数据；跨版本转换的动画效果需另行检查。
