# Live2D / Spine 编辑器工作流

## 打开与另存

1. 将模型、已解包目录或资源包拖入“资源预览”。Live2D 右侧仅有“动画与参数 / 显示与交互”，显示当前 / 总时长，并支持按 ID 搜索全部参数。可冻结当前姿态、调节参数或拖动时间；解除冻结时会从头重新播放该动作。参数列表只同步可见行，隐藏工具页停止同步。刷新与关闭位于来源附近，信息日志在左栏底部。图片使用中央大图和右侧竖向列表。ArtMesh、Part 状态、选区 PSD 与可保存的动作编辑均在编辑器中完成。
2. 有效模型载入后，点击“打开 Live2D 编辑器”或“打开 Spine 编辑器”。图片预览没有此按钮。也可从主侧栏进入编辑器直接打开模型。
3. 编辑器复制当前模型及依赖到独立工作会话。即使来源来自临时解包目录，后续切换预览也不会破坏编辑器资源。
4. 完成后用顶部“保存工程”另存到新的工程目录。Live2D 工程以根 `model.json` 为入口，配套 `lpk_live2d_editor.json` 记录编辑状态、当前皮肤与相对资源路径；皮肤库位于 `skins/`，使用过的 PSD 与 ViewerEX 子工程位于 `psd/`、`mods/`。搬移整个目录后仍可重新打开此文件继续编辑。打开另一模型或关闭程序时，会统一检查未保存修改；后台任务结束前不能切换或关闭。

Spine 若在预览中经过兼容转换，编辑器使用当前预览的版本；界面保留版本提示。源文件不会被转换缓存或另存操作覆盖。

Live2D 通用预览默认根据实际可见内容适配完整轮廓，并在窗口变化时保留适配模式；手动缩放、平移或旋转会退出，“适配模型”按钮可恢复。勾选“切换后自动播放”会在初次载入成功后播放第一个有效动作，之后切换动作也会播放；关闭此项、没有动作或已冻结姿态时不进行初始自动播放。

## Live2D

四个主入口为“动画与参数 / 部件与选区 / 外观 / 导出”。动画任务默认显示时间轴，其他任务默认收起；手动选择会按任务记住。当前编辑皮肤与工作修改状态常驻，任务进度、结果和错误统一显示在底部，可展开完整详情。

- 在“动画与参数”搜索参数名或 ID，调整已有参数并查看模型变化。
- 时间轴上方的动作下拉框支持搜索；输入文字只筛选现有动作，按 Enter 选择唯一或完全匹配的结果。旁边的“＋ / − / 复制”分别新建、删除和复制动作。新建与复制先命名，删除需确认且可撤销；新建不是添加关键帧。
- 选择动作与参数轨道后添加关键帧，也可将当前选中参数值写入当前时间。另存保留原有 Live2DViewerEX 命令；仅提供运行时命令、没有动画文件的条目不作为可编辑动作。
- 在“部件与选区”左侧搜索并 Ctrl/Shift 多选部件，右侧查看 UV 与局部预览，两列可拖动调整。UV 列可收起，公共栏仍可批量隐藏、恢复或调整所选 ArtMesh 的不透明度，恢复可见会保留所设数值。所属 Part 的原有控制保留在可展开设置中。这些状态保存在副本编辑记录中，不重新编译 MOC。
- “外观”宽屏左侧集中显示皮肤管理与图集，右侧展开 PSD 流程；窄屏自动改为上方皮肤与图集、下方 PSD。两种排布分别记住分栏尺寸。图集区显示当前皮肤与图集。拖入一张同尺寸图片或点“替换”，只改当前工作图集；多张图片从左侧导入并确认映射。选择外部编辑器并保存后，文件监视器等待短暂稳定期，只读取变化的图集并更新预览；临时不完整的保存会重试，失败后恢复上次有效图集。修改作用于工作副本。
- 将模型文件、模型目录或图片拖入皮肤管理区并命名为新皮肤。自动匹配要求相同 MOC 摘要，或 Cubism Core 实际读取的 ArtMesh 图集索引、UV 与三角形一致；只有尺寸相同不够。缺少兼容证据时，手动确认每张图片对应的图集页，未映射页保留当前工作贴图。跨模型导入只取贴图，不替换工程 MOC、参数或动作。
- 选择当前皮肤会应用它并形成一次撤销记录。“原始皮肤”不可改名或删除。具名皮肤保存独立快照；工作贴图可保存为新皮肤，切换前未收录的修改会自动保留为工作编辑。打开模型或浏览列表不会自动制造修改，也不会建立 PSD/MOD 子工程。
- “外观”下方常驻“生成 / 回写 / 历史”，无需额外打开，也无需在图集与 PSD 之间切换。首次在后台准备不可变的私有基准；默认名称与姿态、模式、画布尺寸直接可见，项目与路径设置可展开。上下及上方左右分隔条记住布局。完整导出、单/多 PSD 回写、元数据、共享 UV、版本管理与外部编辑器能力保留；PSD 计算在独立子进程中运行，失败后保留工程并可重试。
- “导出”分为“完整 Live2D 模型”和“ViewerEX 点击换装”。普通出口使用当前动作与所选皮肤，可选择含未收录修改的当前工作贴图；输出不包含皮肤库或 PSD/MOD 工作台数据，也不新增 ViewerEX 换装配置。保留完整编辑工程请用顶部“保存工程”另存完整工程副本。
- ViewerEX 高级区保留“工程 / 模型与皮肤 / 换装与导出”三个工作页，包含工程管理、卡片排序、主模型、贴图映射、ArtMesh/HitArea 和配置。工程搜索列出当前 `mods/` 中的工程及旧版记录；外部工程会导入副本。要以当前编辑作为主模型，执行“添加当前皮肤 → 设为主模型或拖到首位 → 重新检查所有贴图映射与触发部位 → 导出”。换主会重新推断映射，不保证保留原手工映射。高级出口按第一张主卡片的动作和映射生成，不自动覆盖自定义主模型。

### PSD 工作台入口

| 工作页 | 操作 |
| --- | --- |
| 导出与姿态 | 默认初始姿态、保存当前预览参数为命名预设、按预设导出 mesh / atlas-components / atlas-artmesh、画布尺寸限制 |
| PSD 回写 | 选择工程内或外部 PSD、指定或自动匹配元数据、外部编辑器、单 PSD 回写、多 PSD 排序优先级回写 |
| 版本与预览 | PSD 源快照、回写与复合历史、图集查看、左侧模型预览、将版本保存为皮肤并应用、送入 ViewerEX |
| 工程与工具 | 新建或导入 PSD 子工程副本、搜索并切换 `psd/` 内或旧版记录中的工程、保存子工程设置、打开目录、静态 ArtMesh 检查器、输出目录与日志 |

导出时从当前皮肤及工作贴图、当前动作生成独立快照，并记录皮肤来源；每次保留自己的 PSD、`.lpkpsd.json` 和 `.baseline/`。后续更改不会覆盖既有基准。回写成功会生成并应用皮肤。再次选择同一 PSD 来源版本会应用已有皮肤，不重复入库；已应用时显示“已应用”。要制作额外副本，显式选择“另存为皮肤变体”，只保存变体而不切换当前皮肤。从皮肤目录可打开其来源 PSD 任务。`psd/` 包含源快照、姿态 PSD、回写历史和预览资源；`mods/` 包含高级换装工程的模型、映射与导出配置。导入旧子工程会复制依赖，原工程保持不变。

在左侧当前模型预览选择“点选”或“框选”，也可从右侧 ArtMesh 列表或图集选择；Ctrl/Shift+点击增减，Ctrl/Shift+框选合并。再点“选区 PSD”，可把选中的完整 ArtMesh 按当前姿态导出；框选不严格裁掉部件边缘，画布按所选部件边界缩小并保留相对位置。重叠位置可从候选列表挑选具体部件。所属 Part 隐藏时会询问是否仅在导出副本恢复可见；当前预览与编辑记录不变。参数姿态仍使部件没有可见内容时，需要先调整姿态再导出。请保留原画布大小、图层位置和尺寸，在 `Original`、`Paint` 或 `AI_Edit` 中绘制；移动、缩放或改画布会被拒绝，重命名不影响绑定。回写仅写选中 UV 内的修改，无修改时 PNG 文件字节保持一致；编辑像素经逆三角映射，缩小导出会降低精度。

所选部件可能与未选部件共用图集像素。默认拒绝这类实际修改，避免误改其他部件；若确实需要共享部件一起变化，在单 PSD 回写中明确勾选“同步修改共享部件”。提示列出潜在共享部件，完成日志与历史记录列出实际受影响的 ID。此选项随 PSD 或元数据切换清零，多 PSD 回写不启用它；互相矛盾的选中层修改仍会拒绝。输出为新皮肤，不修改 MOC 或源文件。

查看 PSD 或 ViewerEX 版本使用同一个原生预览区并标明只读来源。CPU 准备在后台完成，快速切换只显示最新请求；取消尚在收尾时会提示稍候再关闭或切换。“返回当前编辑”会恢复参数、所属部件状态和时间线，不丢弃未保存动作。PSD 版本入库前核对 MOC、贴图数量、顺序与尺寸；新增皮肤与应用是一次可撤销操作，撤销同时恢复当前皮肤与贴图，不以旧快照覆盖动作。“用于 ViewerEX 换装”把版本贴图配合当前动作快照送入高级工程。

皮肤服务接口已为后续 MCP 接入预留；本轮没有新增皮肤 MCP 工具。现有动画 MCP 的连接与调用见 [动画 MCP 使用说明](animation-mcp.md)。

## Spine

- 骨骼树、图层顺序和图集部件与原生模型预览联动。
- 选择骨骼可修改设置姿态；动画平移与旋转是相对设置姿态的偏移，缩放是倍率。
- 在可搜索的动作下拉框中选择现有动作；旁边“＋ / − / 复制”用于新建、确认删除和命名复制，均可撤销。选择骨骼及通道编辑数值关键帧；slot 的 attachment 与显示状态可写入当前时间。
- 图集部件可导出 PNG 或用同尺寸 PNG 替换，保持原裁切范围。旋转及预乘 Alpha 自动处理。
- 输出为骨骼 JSON、atlas、贴图和编辑记录的独立目录。此页不会直接生成官方 `.spine` 工程；需要官方工程时，另用版本转换页与已安装的官方编辑器。

## 时间线与曲线

关键帧工具的“＋”在当前时间给当前轨道添加关键帧，与动作下拉框旁的“新建动作”按钮分开，悬停提示会说明作用。拖动菱形修改关键帧时间，拖动曲线节点修改时间和数值。Live2D 支持线性、阶梯、反向阶梯和贝塞尔插值；Spine 支持线性、阶梯和贝塞尔。可拖动贝塞尔控制点或输入控制点数值，数值表可展开精确编辑。页面提供撤销、重做、播放、暂停与循环，隐藏页会暂停播放。

运行时数据不能完整还原作者的 `.cmo3` / `.spine` 创作工程。本程序编辑已有参数、骨骼与动画结构；缺失的绑定、原始网格创作信息及 Live2D 形变参数不会自动生成。未支持的动画轨道保留原数据；跨版本转换的动画效果需另行检查。
